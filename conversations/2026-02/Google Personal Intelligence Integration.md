## The minimum viable architecture

### 1) A user-owned storage “vault”
Since you’re already living in Drive/Keep, Drive is a natural first substrate.

**Folder layout (created automatically):**
- `/WilliamCore/00_KERNEL/`
- `/WilliamCore/10_LIBRARY/` (finished products: book, essays)
- `/WilliamCore/20_HEAT/` (corrections, arguments, unfinished notes)
- `/WilliamCore/30_LOGS/` (interaction traces, optional)
- `/WilliamCore/40_PACKETS/` (generated context packets)

That alone makes it feel “real.” It becomes a visible object.

### 2) A retrieval index
You need a way to fetch the right chunks fast:
- chunk text
- compute embeddings
- store metadata (source, timestamp, tags, “heat” vs “library”)
- retrieve top-k per user query

This can be hosted:
- locally (later), or
- in a small cloud function (first), with the Drive vault as the source of truth.

### 3) A “packet composer”
Given a user message, it builds a short context packet like:

- **Kernel rules (always)**
- **Most relevant heat excerpts (preferred)**
- **Relevant library excerpts**
- **Constraints** (tone, “don’t drift into metaphysical atheism,” etc.)
- **Task directive** (summarize, plan, write, debug)

Then it hands *that* to whichever provider is being used.

### 4) A wrapper agent
This is the chat surface that users actually talk to (first version).
- Gemini App / AI Studio App Builder is fine as the “front door”
- Later, you can add Telegram/Discord/SMS/WhatsApp style surfaces

But the wrapper agent must be dumb in a good way:
- It doesn’t try to be the personality
- It routes, retrieves, composes packets, and calls the chosen tool

That’s exactly the AIM/MSN vibe: you aren’t switching apps, you’re switching **intent**.

## The core trick that makes it *actually* work
You already named it:

Finished products create the **shadow**.  
But **repair logs** create the *real thing*.

So your onboarding must capture “heat” early.

### Onboarding flow (10 minutes)
1) Import finished artifacts (Drive/Docs/PDF/text)
2) Ask 5–10 “tuning prompts” that force correction:
   - “Here is a paragraph. Rewrite it in my voice.”
   - “Here is a claim. Argue against it the way I would.”
   - “Here’s a misunderstanding people have about me. Fix it.”
3) Every correction becomes HEAT.

You can get a usable co-construct in a single session if you design the prompts to provoke refusal and repair.
