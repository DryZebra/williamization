# Excel Tracker for Lifts

## User

Create a mobile-optimized Excel spreadsheet (.xlsx) for tracking construction lift equipment. The design must be simple, vertical, and easy to read on a phone screen.

Please structure the file with two tabs: "Tracker" and "Data".

Tab 1: "Tracker" (Main Interface)
Columns (Left to Right):
1. LIFT ID (Column A): Pre-fill rows with "Lift #1" through "Lift #20". Make this column Frozen so it stays visible when scrolling right.
2. STATUS (Column B): Create a Dropdown Menu with options: "Available", "In Use", "Charging", "Needs Repair".
3. OPERATOR (Column C): Leave blank for text entry (Crew Name).
4. LOCATION (Column D): Create a Dropdown Menu referencing the location list in the "Data" tab.
5. BATTERY CHECK (Column E): A simple Checkbox or Dropdown (Options: "Good", "Needs Charge").
6. NOTES (Column F): Blank text field for logistics (e.g., "Moving to DSM 2 after lunch").

Formatting Requirements for "Tracker":
- Freeze the Top Row (Headers).
- Freeze the First Column (Lift ID).
- Set Row Height to 30 (to make it easy to tap on mobile).
- Apply Conditional Formatting to the "STATUS" column:
  - If cell contains "Available" -> Fill Green, Text Dark Green.
  - If cell contains "In Use" -> Fill Red, Text White.
  - If cell contains "Charging" -> Fill Yellow, Text Black.
  - If cell contains "Needs Repair" -> Fill Grey, Text Black.

Tab 2: "Data" (Hidden/Reference)
Generate a list of locations in Column A to be used for the Column D dropdown in the Tracker.
Please generate these exact permutations:
- CUB (Sectors 1, 2, 3, 4)
- DSM 1 (Sectors 1, 2, 3, 4)
- DSM 2 (Sectors 1, 2, 3, 4)
- DSM 3 (Sectors 1, 2, 3, 4)
- DSM 4 (Sectors 1, 2, 3, 4)
- Charging Area
- Maintenance Shop
