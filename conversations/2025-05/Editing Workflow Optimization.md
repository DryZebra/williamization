#### **2. Paste One Paragraph or Section at a Time**

#### **3. For Larger Rewrites, Use Shared File Tools**

- Paste the full chapter into a Google Doc or GitHub Gist.

> “I’m pasting in sections of this document. You have the full file as reference—use it to ensure continuity.”
