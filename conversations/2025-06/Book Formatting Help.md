#### **Option 2: Use Termux + Pandoc (advanced, most control)**
- **What it is**: Termux is a terminal emulator. Pandoc is a universal document converter. This method gives you full, fine-tuned EPUB control.

**Steps:**
1. Install **Termux** from F-Droid (not Play Store).
2. Inside Termux, run:
   ```bash
   pkg update
   pkg install pandoc
   ```
3. Place your `.docx` in a shared directory (like `/sdcard/Download`).
4. In Termux, convert with:
   ```bash
   pandoc /sdcard/Download/Materialist_Christianity_With_Cover.docx -o /sdcard/Download/Materialist_Christianity.epub --metadata title="Materialist Christianity" --metadata author="Ezra Byrd"
   ```

Now you've got a 100% local EPUB.
