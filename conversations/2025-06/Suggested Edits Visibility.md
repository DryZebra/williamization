# Suggested Edits Visibility

## User

In Google docs can everyone see everyone's suggested edits?

## Assistant



## Assistant

Yes, in **Google Docs**, **everyone with "Commenter" or "Editor" access** can see all suggested edits (also called **"Suggestions"**). These suggestions show up in the right-hand margin and are color-coded per user, so you can see who made each suggestion.

Here’s how it works:

- **Viewer**: Cannot see or make suggestions.
- **Commenter**: Can **see and make suggestions**, but cannot directly edit the document.
- **Editor**: Can see suggestions, make them, or accept/reject them.

So if multiple people are suggesting edits, **everyone with sufficient access can see all of them**, along with the author and timestamp.
