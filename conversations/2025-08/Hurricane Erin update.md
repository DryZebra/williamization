## 1. **Observational Data (Raw Weather Records)**

### a) **Integrated Surface Database (ISD)**
- A massive NOAA/NCEI archive of **hourly and synoptic surface observations** from thousands of weather stations worldwide — including Raleigh-Durham Airport (RDU). The data is updated hourly in near–real time.  
- Format: Raw and machine-friendly (often CSV or similar).  
- Ideal for: Anything from scripting your own analysis to feeding into models or apps.  
citeturn0search21

### b) **NCEI Climate Data Online (CDO) Web Services**
- A RESTful **API** offering historic daily, monthly, and some sub-daily data like temperature, precipitation, wind, etc.
- Requires a **free token** to access.  
- Data retrieved in JSON format — perfect for coding and automation.  
citeturn0search8turn0search2

### c) **Local Weather Archive (Raleigh-Durham) via Data.gov**
- A curated dataset containing historical observations from RDU Airport, in both **CSV and JSON format**.
- This archive is not continuously updated (“it is not being updated”), but it’s easily downloadable and can plug straight into data tools.  
citeturn0search3turn0search5

### d) **Station-Level Access via NOAA / NCDC Interface**
- For RDU (station ID: `USW00013722`), you can access daily summaries, view date ranges, and download selected data (by year, month, or day) through NOAA's station detail portal.  
citeturn0search17

## 2. **Forecast & Model Data (Gridded/Forecast Data)**

### a) **NWS API (api.weather.gov)**
- Accessible with no token — returns RESTful JSON (often GeoJSON).
- You can retrieve **current conditions**, **hourly forecasts**, **alerts**, and more for a specific location (by lat/lon).  
citeturn0search10

### b) **National Digital Forecast Database (NDFD)**
- Contains gridded forecast data (temp, precipitation, cloud cover, etc.) in formats like **GRIB2**, which you can decode (to CSV, shapefile, NetCDF, etc.) using GIS tools.  
citeturn0search23

---

## 3. **Reanalysis & Global Models (Historical Gridded Data)**

### a) **NCEP/NCAR Reanalysis**
- A continuous, globally gridded dataset of atmospheric states (pressure, temp, wind, etc.) from 1948 to the present.  
- Distributed in **NetCDF or GRIB** formats — widely used in climate and research modeling.  
citeturn0search20

### b) **Monthly Climatic Data for the World (MCDW)**
- While not granular like hourly station data, this dataset provides **monthly means** (temperature, precipitation, pressure, etc.) across global stations.  
- Offers final, quality-controlled data — but with a 4–6 month delay.  
citeturn0search22

- Some data may require a login, but the **Station Scout** and **Data Viewer** are freely accessible and helpful.
