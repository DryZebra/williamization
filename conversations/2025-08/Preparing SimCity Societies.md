# Preparing SimCity Societies

## User

Before I stick the Sim City Societies disc in my Windows 11 PC, should I prepare in any way?

## Assistant



## Assistant

Yes — it’s smart to prepare a bit before trying to run **SimCity Societies** on Windows 11, since the game is from 2007 and wasn’t built for modern systems. Here’s what I’d suggest:  

---

### 1. Check the disc itself  
- **Inspect for scratches/dust.** Clean with a microfiber cloth if needed.  
- Make sure your optical drive actually reads older discs reliably — some slim drives struggle with them.  

---

### 2. Prepare Windows 11  
- **Disable AutoRun.** Sometimes old installers try to autorun in ways that can hang modern systems. Just open the disc in File Explorer and run `setup.exe` manually.  
- **Run installer in compatibility mode.** Right-click → *Properties* → *Compatibility* → set to *Windows XP (SP3)* or *Windows Vista*. Also check *Run as administrator*.  

---

### 3. Know the DRM issue  
- The retail disc version of **SimCity Societies** uses **SecuROM DRM**, which often doesn’t work on Windows 10/11 because Microsoft removed support for it. That means the disc might install fine but refuse to launch.  
- If that happens, you’ll need either:  
  - **An official patch** (EA released updates that sometimes eased DRM issues), or  
  - **The no-DRM digital version** (like the one that used to be on Origin/Steam), which works better on modern systems.  

---

### 4. Extra precautions  
- Make a **system restore point** before installing, in case the SecuROM driver causes problems.  
- If you want to avoid disc spinning every time, consider installing fully and then applying the latest patch (v1.0.3.0).  

---

👉 Bottom line: it *might* run directly after installation, but because of SecuROM, don’t be surprised if the game refuses to launch on Windows 11. The safest prep is checking for the latest patch and maybe grabbing the DRM-free version if you want guaranteed playability.
