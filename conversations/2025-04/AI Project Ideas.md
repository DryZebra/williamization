## **Step 1: Set Up Your Dev Environment**

We’ll use **Expo + React Native**, which makes mobile app development crazy fast and easy. You can test on your phone instantly, and it's cross-platform.

### **1. Install Node.js (if not already)**
Go to [https://nodejs.org/](https://nodejs.org/)  
Download **LTS version**, install with default settings.

### **2. Install Expo CLI**
Open your terminal and run:
```bash
npm install -g expo-cli
```

### **3. Create the App**
Once installed, run:
```bash
expo init paladins-app
```
Choose:
- **Blank (TypeScript)** when prompted for template.
- Name: `paladins-app`

Then:
```bash
cd paladins-app
npm start
```

This launches Expo. It’ll give you a QR code to scan with your phone (via the [Expo Go app](https://expo.dev/client)) to test instantly.
