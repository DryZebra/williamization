Objective:

---

I. PHILOSOPHY

A modern peasant diet: nutritionally sound, seasonally adapted, cheap, and fast.
Every meal is prepared fresh daily, using only whole ingredients and simple methods (one pot/pan max, ≤60 min active time).

The system must:

Eliminate waste by using every purchased ingredient by week’s end.

Compute weekly grocery inputs from the sum of all individual meal recipes.

Maintain caloric and nutrient balance for both adults.

Remain Walmart-realistic — all items sold in standard stores or Walmart .com.



---

II. STRUCTURE OF OUTPUT

Produce a printable, navigable PDF divided into four seasonal sections (Winter / Spring / Summer / Fall).

For each of 52 weeks include:

1. Weekly Overview

Calorie and macro targets (per person).

Short paragraph on seasonal focus and key nutrients.


2. Meal Breakdown (7 days)

Each day lists breakfast, lunch, and dinner separately:

Dinner – Day 56  
Recipe: Pan-fried chicken thighs (4 oz/person) with potatoes and onions  
Ingredients per day:  
• 2 chicken thighs (approx 8 oz total)  
• 1 medium potato  
• ½ onion  
• 1 tsp oil, salt, pepper  
Instructions: Season → pan fry → serve. 25 min.

3. Weekly Aggregated Grocery List

Automatically derived by summing all daily recipes:

Week 14 – Grocery List  
Protein: 4 chicken thighs, 2 lb ground beef, 2 cans tuna  
Starch: 1 bag (5 lb) potatoes, 2 cups rice  
Veg: 3 onions, 1 bag frozen broccoli  
Pantry: oil, salt, pepper

Each item uses Walmart naming (e.g., Great Value Boneless Skinless Chicken Thighs 2.5 lb bag).

4. Notes

Storage tips for unused staples.

Optional substitutions if items unavailable.



---

III. NUTRITIONAL & PRACTICAL CONSTRAINTS

Parameter	Target / Rule

Calories	~2 400 kcal per person per day
Protein	170–180 g
Fat	110–120 g
Carbs	130–160 g
Meal prep time	≤ 60 min total per day
Equipment	1 pan + 1 pot max
Cost awareness	Lowest total cost using Walmart SKUs; prioritize dry staples, frozen veg, eggs, canned fish
Batch cooking	Prohibited — every meal cooked fresh
Repetition	Allowed; same dinner multiple nights fine
Ingredient carry-over	Only staples (oil, salt, flour, milk, eggs)



---

IV. AGENT LOGIC (COMPUTATIONAL INSTRUCTIONS)

1. Generate 52 weeks × 7 days × 3 meals.


2. For each meal: define

Title, description, prep time.

Exact ingredient amounts per person.



3. Aggregate weekly totals for each ingredient into a grocery list.


4. Cross-check availability at Walmart; replace unavailable items with cheapest in-stock equivalent.


5. Optimize for cost + simplicity while preserving nutrition.


6. Assemble PDF with tables, checkboxes, and seasonal dividers.




---

V. SEASONAL THEMES

Season	Core Foods	Example Dinners

Winter	potatoes, cabbage, canned fish, oats	potato-onion-egg skillet
Spring	greens, eggs, trout, berries	trout + collards
Summer	tomatoes, okra, melons, beans	rice + beans + fried egg
Fall	sweet potatoes, apples, pork, kale	pork + sweet potato hash



---

VI. STYLE & DELIVERY

Tone: plain, utilitarian, like a tradesman’s manual.

Format: black-and-white printable PDF with seasonal headers.

Optional CSV export: week, ingredient, quantity, brand.



---

✅ 52 weeks × 7 days of meals.
✅ Every meal cookable in under 1 hour, no batching.
✅ Weekly grocery list derived from daily meals.
✅ All ingredients Walmart-available.
✅ Nutritionally adequate for two adults.

Balanced Closed‑Loop Meal Plan Generator
======================================

This script improves upon the earlier closed‑loop meal planner by ensuring that every recipe in the library is actually used and that weeks contain greater variety.  It prohibits repeating the same base recipe more than once per week and treats minor variations of a recipe (e.g., "with herbs") as the same base.  Within each season the algorithm groups meals by their primary bulk ingredient (rice, oats, potatoes, etc.) and rotates these groups so that opened packages are consumed over consecutive weeks while still introducing different recipes each day.

Usage:  Run `python3 balanced_plan_generator.py` to generate the file `balanced_closed_loop_plan.md` in the shared directory.

    """Extract the base name of a recipe by removing anything after ' with '."""
    return title.split(' with ')[0].strip()

    """Return the first bulk ingredient found in the ingredient list, else 'misc'."""
    for ing in ingredients:
        if ing in BULK_ITEMS:
            return ing
    return 'misc'


def build_balanced_schedule(meal_library: list) -> list:
    """Build a schedule where each recipe base appears at least once and no base repeats within a week.

    This function operates by season and meal category.  For each season it divides the meals into
    groups based on their primary bulk ingredient.  For each of the 13 weeks in the season it then
    selects a mix of base recipes from different groups such that each base is unique within the week
    but repeated across the season to fill all slots.  Minor variations of the same base (e.g.,
    "Pork & Sweet Potatoes" and "Pork & Sweet Potatoes with Herbs") are treated as the same base.
    """
    # Preprocess meals: compute base name and major ingredient
    for meal in meal_library:
        meal['base_name'] = extract_base_name(meal['title'])
        meal['major_ingredient'] = determine_major_ingredient(meal['ingredients'])

    # Organize meals by season -> category -> base_name -> list of meal variants
    seasons = ['Winter', 'Spring', 'Summer', 'Fall']
    meals_by_season_cat_base = defaultdict(lambda: defaultdict(lambda: defaultdict(list)))
    for meal in meal_library:
        # Add to its specific season
        meals_by_season_cat_base[meal['season']][meal['category']][meal['base_name']].append(meal)
        # Also add to the 'Any' season for fallback
        meals_by_season_cat_base['Any'][meal['category']][meal['base_name']].append(meal)

    # Build schedule list (52 weeks x 7 days)
    schedule = [None] * (52 * 7)
    week_index_global = 0
    for season in seasons:
        for category in ['Breakfast', 'Lunch', 'Dinner']:
            base_to_variants = meals_by_season_cat_base[season][category]
            if not base_to_variants:
                # If no season‑specific meals, fall back to any season
                base_to_variants = meals_by_season_cat_base['Any'][category]
            # Determine major ingredient grouping
            group_to_bases = defaultdict(list)
            for base, variants in base_to_variants.items():
                # Determine major ingredient for base by checking first variant's ingredients
                first_variant = variants[0]
                major = first_variant['major_ingredient']
                group_to_bases[major].append(base)
            # Flatten list of all bases
            all_bases = list(base_to_variants.keys())
            # Determine how many total slots needed for this season (13 weeks * 7 days)
            total_slots = 13 * 7
            # Determine how many times each base should appear: distribute evenly
            base_counts = {base: total_slots // len(all_bases) for base in all_bases}
            remainder = total_slots % len(all_bases)
            # Distribute remainder to some bases
            for base in random.sample(all_bases, remainder):
                base_counts[base] += 1
            # Expand into list of base names to fill slots
            base_pool = []
            for base, count in base_counts.items():
                base_pool.extend([base] * count)
