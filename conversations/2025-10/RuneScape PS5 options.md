Using your ISP’s (carrier) DNS is fine for many people, but if privacy, security, or filtering matters, switching to a privacy-focused DNS is usually better. Below is a breakdown of trade-offs + good options + how to pick/implement one.

---

## ⚙️ Why you might not want to use carrier DNS

**Pros (carrier DNS):**
- It’s automatic: your router/modem gets it, works out of box.
- Often low-latency in local networks (if provider’s DNS servers are close).
- Reliable (ISP ensures it stays up, as part of their infrastructure).

**Cons (privacy & security risks):**
- Your ISP can log your DNS queries, which reveals which domains you visit (even if the rest of the traffic is encrypted).  
- Some ISP DNS servers inject ads, captive portals, or block/redirect certain domains.  
- Less control over filtering (malware, tracking domains, etc.).  
- If the ISP’s DNS is compromised or manipulated (e.g. DNS hijacking), your queries could be misdirected.

So a good privacy-focused DNS can give you more control, better security features (e.g. blocking malicious domains), and reduced trust in your ISP.

## 📌 What “privacy-focused” should mean

When evaluating, a good DNS resolver should:

1. **Support encrypted DNS** (DNS over TLS, DNS over HTTPS, or newer like DNS over QUIC) so your DNS queries aren’t visible to local network eavesdroppers.
2. **Minimize or avoid logging** client IPs or full query history.
3. **Use “query name minimization”** (only send the necessary parts of a domain to upstream servers). Many resolvers do this by default.  
4. **Resist censorship / manipulation** (i.e. don’t inject ads or redirect domains).
5. **Good network performance / geographical presence** so it’s fast for you.

---

## 🛠 Router setup: where to configure DNS, and what to watch out for

- You generally want to set DNS **at the router level**, so all devices inherit it. If configured only on a few devices, others might still use carrier DNS.  
- Not all routers support encrypted DNS (DoT / DoH) at router level — sometimes they only support plain DNS. In that case, either your router will send encrypted queries to the DNS provider (if supported) or send plaintext to it, which is less ideal.
- Some ISP devices (modem/router combos) might override DNS settings or enforce their own DNS — check if “DNS override / forced DNS” is present.
- If you set a custom DNS, keep a fallback (e.g. carrier DNS) in case your chosen DNS provider is unreachable.
- After switching, flush DNS caches on your devices so they don’t keep old records.
