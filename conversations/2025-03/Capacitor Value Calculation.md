# Capacitor Value Calculation

## User

What is the value of the capacitor? Given: R=80 Ω XL=75 Ω XC = 99 Ω
EAPP = 120 V, 60 Hz

## Assistant



## Assistant

To find the value of the capacitor (C), we use the capacitive reactance formula:

\[
X_C = \frac{1}{2\pi f C}
\]

### Given:
- \( X_C = 99 \, \Omega \)
- \( f = 60 \, \text{Hz} \)

### Solving for \( C \):
\[
C = \frac{1}{2\pi f X_C}
\]

\[
C = \frac{1}{2 \cdot \pi \cdot 60 \cdot 99}
\]

\[
C \approx \frac{1}{37340.1} \approx 2.678 \times 10^{-5} \, \text{F}
\]

\[
C \approx 26.78 \, \mu\text{F}
\]
